# Lab 1: Introduction to Natural Language Processing

This lab is a general introduction to NLP. It covers the basic ideas and terms used in the field before any hands-on coding starts.

## Topics covered

- What NLP is and what it is used for
- The three main things that make current NLP possible: data, compute, and algorithms
- Why NLP is a hard problem (ambiguity, spelling errors, words that sound the same, word order changing meaning)
- Common text file types used in NLP (CSV, text files, JSON, SQL, HTML, PDF, DOCX)
- NLP libraries, with a short introduction to NLTK
- Arabic NLP libraries (Camel-Tools, PyArabic, Farasa)
- Common NLP applications: information extraction, machine translation, and sentiment analysis
